# admin-mvp

`apps/admin-mvp` 是量表网页端项目的内部后台子项目。当前后台已经从“离婚力量表后台 MVP 第一轮”扩展为两套量表共用的线索管理与详细报告后台。

## 当前支持的量表

- 离婚力量表。
- 配偶高自恋特质与高冲突婚姻风险自测量表。
- 历史离婚力量表记录如缺少 `assessment_type`，后台按离婚力量表兼容展示。

## 当前能力

- 最小登录鉴权。
- 受保护的后台列表页 `/leads`。
- 量表类型识别与筛选。
- 搜索、筛选、提交时间区间筛选与轻分页。
- 结果等级筛选按量表类型区分，避免“准备充分”筛出新量表“高风险”。
- 当前筛选结果 CSV 导出。
- 批量勾选删除记录。
- 单条详情页 `/leads/[id]`。
- 两套量表详情页分流展示。
- 后台跟进字段保存。
- 服务类型多选维护。
- 两套量表单条详细报告页 `/leads/[id]/report`。
- A4 网页端报告预览。
- 移动端长图报告预览。
- 当前预览模式 PNG 导出。
- A4 PDF 导出。

## 服务类型选项

当前后台服务类型为多选，选项包括：

- 未明确
- 咨询服务
- 包离服务
- 离婚陪跑
- 诉讼代理
- 协议文书
- 离婚谈判
- 跨境甄选
- 其他

历史服务类型值仍保留中文展示兼容，不建议继续新增旧值。

## 批量删除说明

列表页支持勾选当前页记录并批量删除。该操作为永久删除，应仅在测试记录验收或明确需要清理数据时使用。

使用前请确认：

- 已选中的确是要删除的记录。
- 删除不会影响后续验收样本。
- 不用真实生产线索测试删除能力。

## 当前不做

- 用户注册登录。
- 用户端报告中心。
- `report_content` 持久化。
- 报告审核定稿系统。
- 报告文件云端存储。
- 完整 CRM。
- 批量报告生成。
- 批量用户画像 / 统计 / 内容赋能分析报告。
- 复杂权限树、角色权限和字段级权限。

## 环境变量

复制 `.env.example` 为 `.env.local` 并填写：

- `NEXT_PUBLIC_SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`（仅服务端读取）
- `ADMIN_MVP_USERNAME`
- `ADMIN_MVP_PASSWORD`
- `ADMIN_MVP_SESSION_SECRET`

不要提交 `.env.local`，也不要在文档、截图或 commit message 中暴露真实密钥、后台密码或 session secret。

## 本地启动

```bash
cd apps/admin-mvp
npm install
npm run dev
```

默认访问 `http://localhost:3000`，会跳转到 `/login`。如根目录前台已占用 3000，Next.js 可能会提示使用其他端口。

## 构建检查

```bash
cd apps/admin-mvp
npm run build
```
