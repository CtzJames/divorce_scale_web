# 网页信息架构与页面文案草案

## 当前前台页面结构

公开前台保持单页测评主流程：

1. 引导页
2. 系统分流题
3. 普通题随机测评
4. 前台结果页

本轮仅调整前台结果页，不进入后台详细报告模块。

## 结果页当前结构

结果页收敛为「简略解释 + 建联转化入口」：

1. 顶部结果总卡
   - 展示结果等级名称
   - 展示跨境 / 非跨境动态总说明
   - 展示总分、动态满分、得分率

2. 维度雷达图
   - 保留动态维度雷达图
   - 按子女 / 跨境分流结果展示 5 / 6 / 7 维
   - 模块底部提供「导出简要结果」按钮

3. 下一步建议与沟通安排
   - 展示已生成的个性化建议文本
   - 页面只直接露出「建议您」
   - 后续完整建议内容以模糊遮罩呈现
   - 保留称呼、联系电话、微信输入框
   - 提示文案为：如需获取完整版测评结果报告与解析，请点击按钮保存您的结果并添加小助理微信
   - 提交成功后在原模块内展开企业微信二维码

## 当前删除的前台展示

结果页不再展示：

- 「这意味着什么」独立说明模块
- 「您当前最需要优先处理的环节」短板卡片模块

说明：短板识别底层逻辑仍保留，用于写库、导出简要结果图和后续后台使用。

## 用户端显示边界

用户端当前只看到简略结果解释、动态雷达图、被遮罩的个性化建议入口和留资建联入口。

七维度完整解析、各分段完整说明和完整版报告正文不在本轮前台展示，后续应放入后台导出的完整版报告能力中处理。
