# 结果分级规则与结果页文案框架

## 当前分级规则

前台仍沿用既有得分率分级规则，不改计分逻辑：

- `high`：得分率 > 80%，页面展示为「从容通关者」
- `mid`：得分率 60%–80%，页面展示为「稳健备战者」
- `low`：得分率 < 60%，页面展示为「急速蓄力者」

说明：`result_level` 仍保存 `high` / `mid` / `low`，前端展示名称由文案配置映射。

## 总分评估文案

结果页顶部总卡展示三项信息：

- 结果等级名称
- 总分评估说明
- 总分 / 动态满分 / 得分率

总分评估说明按两层条件动态选择：

- 结果等级：`high` / `mid` / `low`
- 跨境分流题：非跨境 / 跨境

因此前台共接入 6 套总说明文案：

- 非跨境 × 从容通关者
- 非跨境 × 稳健备战者
- 非跨境 × 急速蓄力者
- 跨境 × 从容通关者
- 跨境 × 稳健备战者
- 跨境 × 急速蓄力者

文案来源为《离婚力测量量表各维度解读细化》第一部分《总分评估结果》。

## 个性化建议生成

前台实际生成完整建议文本，但结果页只开放开头「建议您」三个字，其余内容以模糊遮罩展示。

建议文本来源为《离婚力测量量表各维度解读细化》第二部分《七维度精细化评估》中各维度各分数段的第二段建议文字。

生成规则：

- 维度均分 < 3：优先层，首句前缀为「建议您」
- 维度均分 3–3.9：次级层，首句前缀为「此外，建议您」
- 维度均分 >= 4：最后层，首句前缀为「最后，建议您」
- 若前一层为空，后续层整体上移，首个实际输出层仍使用「建议您」
- 同一层内固定按 D1 → D2 → D3 → D4 → D5 → D6 → D7 输出

该建议文本仅用于前台转化展示，不等同于后台完整版报告正文。
