# 配偶高自恋特质量表网页信息架构与页面文案草案 V1

## 1. 文档用途

本文档用于整理《配偶高自恋特质与高冲突婚姻风险自测量表》第一阶段公开前台网页的信息架构、页面模块层级、用户可见文案、交互状态与简版结果图导出内容。

本文档承接以下底座文件：

1. 《配偶高自恋特质量表网页端产品与开发方案 V1》；
2. 《配偶高自恋特质量表题目-维度-计分映射表 V1》；
3. 《配偶高自恋特质量表结果分级规则与结果页文案框架 V1》。

本文档不是：

- 题库映射表；
- 计分规则主档；
- 数据库字段方案；
- 后台适配方案；
- Codex 开发 prompt；
- 第二阶段详细报告文案主档。

本文档主要回答以下问题：

1. 新量表前台应包含哪些页面或页面状态；
2. 用户从进入页面到提交结果的完整路径是什么；
3. 每个页面模块应展示哪些内容；
4. 第一阶段结果页应展示哪些文案，不展示哪些文案；
5. 留资区如何承接咨询转化；
6. 简版结果图导出卡应包含哪些内容；
7. 如何在页面层面避免诊断化、标签化和恐吓式营销。

## 2. 前台整体定位

### 2.1 页面定位

本量表前台页面定位为：

**婚姻互动风险识别型在线自测页面。**

它应让用户在较低心理负担下完成以下动作：

1. 理解量表用途与边界；
2. 完成 40 题自测；
3. 获取风险等级与五维风险结构；
4. 识别是否存在高风险触发信号；
5. 保存简版结果图；
6. 在需要时提交联系方式，进入后续专业咨询承接。

### 2.2 页面语气

页面整体语气应保持：

- 专业；
- 克制；
- 清晰；
- 有安全意识；
- 有行动指向；
- 不恐吓；
- 不诊断；
- 不娱乐化。

页面不宜使用：

- 人格测试式戏谑表达；
- “测一测你对象是不是 NPD”式标题；
- 过度煽动恐惧的营销文案；
- 直接替用户作出离婚决定的表达。

### 2.3 与离婚力量表前台的关系

本量表应作为同仓库下的第二套独立前台入口存在。

暂定入口：

`/narcissism-risk`

页面体验可参考离婚力量表既有成熟路径，包括：

- 首页引导；
- 测评说明；
- 卡片式答题；
- 进度展示；
- 结果页模块化呈现；
- 留资提交；
- 简版结果图导出。

但文案、结果方向和风险提示必须独立，不得沿用离婚力量表“准备度”语义。

## 3. 前台页面结构总览

第一阶段建议采用单入口、多状态页面结构。

用户主流程为：

1. 入口页 / 首页；
2. 测评说明页或说明区；
3. 正式答题页；
4. 结果页；
5. 结果页内留资区；
6. 简版结果图导出能力。

页面结构可实现为单个路由内的状态切换，也可拆分为组件化页面状态。

推荐路由：

`app/narcissism-risk/page.js`

推荐核心页面状态：

| 页面状态 | 功能 |
|---|---|
| `intro` | 首页与开始测评入口 |
| `guide` | 测评说明与边界提示 |
| `test` | 40 题随机顺序答题 |
| `result` | 结果页展示、留资、导出 |

也可以将 `intro` 与 `guide` 合并为一个开始页，以降低开发成本。

## 4. 页面一：首页 / 入口页

### 4.1 页面目标

首页承担三个任务：

1. 让用户快速知道这是什么测评；
2. 让用户理解它不是人格障碍诊断；
3. 引导用户开始测评。

首页不宜承载过多长文解释，详细边界说明可放在测评说明页或折叠区。

### 4.2 首页建议模块

首页建议包括：

1. 顶部标签；
2. 主标题；
3. 副标题说明；
4. 适用场景卡片；
5. 重要边界提示；
6. 开始测评按钮。

### 4.3 首页顶部标签

建议文案：

> 婚姻互动风险自测工具

可选文案：

> 高冲突婚姻风险识别

不建议使用：

> NPD 测试

> 测测你的配偶是不是自恋型人格

### 4.4 首页主标题

建议标题：

> 配偶高自恋特质与高冲突婚姻风险自测量表

如页面视觉需要更短标题，可使用：

> 高冲突婚姻风险自测

副标题中再补足完整量表名称。

### 4.5 首页副标题

建议文案：

> 如果您在婚姻中长期感到被否定、被控制、被操控，或正在经历高压沟通、分居、离婚协商、财产分割、子女安排等冲突场景，可以通过本量表初步梳理关系中的高自恋互动特征与高冲突风险信号。

### 4.6 适用场景卡片

模块标题建议：

> 适用于哪些情况？

卡片内容建议：

1. **长期被否定或贬低**  
   对方经常否认您的感受，或把您的正常反应说成“太敏感”“不讲理”。

2. **沟通容易升级为攻击**  
   普通分歧很快变成指责、羞辱、翻旧账、报复性表达或输赢对抗。

3. **存在操控或第三方卷入**  
   对方通过亲友、孩子、钱款、共同财产或外部叙事向您施压。

4. **分居或离婚协商困难**  
   对方反复拖延、改变说法、制造程序性消耗，或在关键议题上持续施压。

5. **担心冲突升级或安全风险**  
   已出现威胁、骚扰、隐私公开、限制行动、自伤他伤威胁等信号。

### 4.7 重要边界提示

建议文案：

> 本量表不用于判断对方是否患有 NPD / 自恋型人格障碍，也不构成临床诊断、心理治疗建议或正式法律意见。它的作用是帮助您初步识别婚姻互动中的风险信号，并为后续是否需要寻求专业支持提供参考。

建议按钮文案：

建议文案：

> 全量表共 40 题，约需 5–8 分钟。请根据长期、反复出现的互动模式作答，而不是仅凭某一次争吵判断。

## 5. 页面二：测评说明页 / 作答说明区

### 5.1 页面目标

测评说明页用于在正式答题前提示用户：

1. 以长期互动模式为依据；
2. 40 题全部必答；
3. 选项含义；
4. 结果仅供风险识别参考；
5. 若存在现实安全风险，应优先处理现实安全。

该页面可作为独立状态，也可放在首页下半部分。

### 5.2 作答说明标题

建议标题：

> 作答前请先了解

### 5.3 作答说明正文

建议文案：

> 请根据您对配偶或伴侣在长期婚姻互动中的观察作答。建议以持续、反复出现的行为模式为主要依据，而不是仅凭某一次争吵或单一事件判断。
>
> 如果您与对方已经进入分居、离婚协商、调解或诉讼阶段，也可以结合对方在这些阶段中的表现进行判断。
>
> 本量表共 40 题，全部题目均需作答。请按照第一反应选择最符合实际情况的一项，无需反复斟酌。

### 5.4 选项说明

建议展示为表格或选项卡：

| 选项 | 含义 |
|---|---|
| 完全不符合 | 几乎没有出现，或与您的长期观察明显不符 |
| 不太符合 | 偶尔出现，但不是稳定模式 |
| 一般符合 | 有一定出现频率，或您不确定强度 |
| 基本符合 | 较常出现，已经对关系产生影响 |
| 完全符合 | 经常出现，且已成为明显互动模式 |

说明：

> 页面计分采用 1–5 分。部分题目为反向计分题，系统会自动换算，您只需根据真实观察作答。

### 5.5 安全提示

建议以醒目但不恐吓的提示卡展示。

标题：

> 如果您正在面临现实威胁，请优先保护安全

正文：

> 如果对方已经出现暴力、限制行动、持续骚扰、公开隐私、自伤他伤威胁，或您与孩子正处于现实危险中，请不要仅依赖线上测评结果。请优先联系可信亲友、报警、寻求庇护、申请保护措施或咨询专业人士。

### 5.6 开始按钮

建议按钮文案：

> 我已了解，开始答题

辅助按钮：

> 返回首页

## 6. 页面三：正式答题页

### 6.1 页面目标

正式答题页用于让用户完成 40 题随机顺序作答。

该页面的重点是：

- 降低作答压力；
- 保持题目清晰；
- 明确进度；
- 保证全部必答；
- 保存随机题序；
- 保证答案按 `question_id` 存储。

### 6.2 答题页结构

建议模块：

1. 顶部进度条；
2. 当前题号进度；
3. 题干卡片；
4. 5 个选项；
5. 上一题 / 下一题按钮；
6. 底部提示；
7. 最后一题提交按钮。

### 6.3 进度显示

建议文案：

> 第 {current} / 40 题

或：

> 已完成 {answered} / 40

进度条按已作答数量更新。

### 6.4 题干展示

题干应直接展示，不显示维度名称和测量重点。

理由：

- 避免用户根据维度猜测“正确答案”；
- 避免强化标签化感受；
- 保持作答沉浸感。

后台和开发配置中保留维度、测量重点即可。

### 6.5 选项展示

选项顺序固定为：

1. 完全不符合；
2. 不太符合；
3. 一般符合；
4. 基本符合；
5. 完全符合。

不设置：

- 不适用；
- 跳过；
- 暂不回答。

### 6.6 自动进入下一题

可沿用离婚力量表体验：用户选择某项后短暂延迟自动进入下一题。

建议同时保留“上一题”按钮，允许用户修改上一题答案。

如开发成本考虑，也可采用手动“下一题”模式，但需要保证移动端点击体验顺畅。

### 6.7 未完成提示

若用户试图提交但仍有题目未答，应提示：

> 还有题目未完成，请完成全部 40 题后再查看结果。

如采用单题顺序答题，通常不会出现大量漏答；如采用列表式答题，则需定位未答题。

### 6.8 答题页底部提示

建议文案：

> 请根据长期、反复出现的互动模式作答。测评结果仅用于风险识别参考，不构成诊断或法律意见。

## 7. 页面四：结果页总结构

### 7.1 结果页定位

第一阶段结果页定位为：

**风险概览 + 五维结构 + 高风险提示 + 轻量行动建议 + 留资承接 + 简版结果图导出。**

第一阶段结果页不是：

- 完整详细报告页；
- 心理诊断报告；
- 法律意见书；
- 后台 A4 报告；
- 移动端长图深度报告；
- PDF 导出页。

### 7.2 结果页建议模块顺序

建议结果页包括：

1. 顶部结果总卡；
2. 五维风险雷达图；
3. 当前较突出的风险维度；
4. 高风险触发提示卡；
5. 下一步建议；
6. 留资与咨询承接区；
7. 简版结果图导出按钮；
8. 免责声明；
9. 重新测评按钮。

移动端可按单列纵向展示。

## 8. 结果页模块一：顶部结果总卡

### 8.1 模块目标

顶部结果总卡用于让用户第一眼看懂：

- 自己的风险等级；
- 总平均分；
- 分数方向；
- 当前结果的大致含义。

### 8.2 展示字段

建议展示：

- 结果等级：低风险 / 轻度风险 / 中度风险 / 高风险；
- 总平均分：例如 3.42 / 5；
- 总分：例如 137 / 200；
- 风险方向提示；
- 四档结果说明文案。

### 8.3 固定提示

建议固定展示：

> 分数越高，代表相关高自恋互动特征与高冲突风险信号越明显。

### 8.4 低风险总卡文案

标题：

> 低风险

短标签：

> 当前高冲突风险信号较弱

正文：

> 您的作答显示，当前关系中与高自恋互动、高冲突升级相关的风险信号整体较弱。对方在多数婚姻互动场景中，可能仍保有一定的协商空间、情绪控制能力和对他人感受的基本回应能力。
>
> 但低风险并不代表关系中完全没有问题，也不代表未来不会发生冲突。若您已经处于分居、离婚协商、财产分割或子女安排阶段，仍建议结合现实情况，理性保存关键沟通记录，并在涉及重大权益时咨询专业人士。

### 8.5 轻度风险总卡文案

标题：

> 轻度风险

短标签：

> 部分互动模式值得留意

正文：

> 您的作答显示，当前关系中已经出现一些与高自恋互动或高冲突婚姻相关的风险信号。这些信号可能表现为对方在部分议题上较强的自我中心、被质疑后的防御反应、对您的感受回应不足，或在冲突中倾向于转移责任、施加压力。
>
> 这一结果并不意味着对方存在人格障碍，也不意味着关系必然会恶化。但它提示您：在继续沟通、协商或推进离婚相关事项时，需要更重视边界、证据和沟通方式，避免在情绪化状态下作出重大决定。

### 8.6 中度风险总卡文案

标题：

> 中度风险

短标签：

> 风险信号已较明显

正文：

> 您的作答显示，当前关系中与高自恋互动、高冲突升级相关的风险信号已经较为明显。对方可能在多个场景中表现出较强的特权感、对批评或不同意见高度敏感、难以回应您的真实感受，或通过情绪、资源、亲友、孩子、叙事控制等方式影响关系走向。
>
> 在这一风险水平下，单纯依靠反复沟通或情绪化争辩，可能难以真正降低冲突。建议您优先梳理关键事实、保存重要证据、减少无准备的正面冲突，并在涉及财产、子女、分居、离婚协商或安全风险时，尽早咨询专业婚姻家事律师或其他专业人士。

### 8.7 高风险总卡文案

标题：

> 高风险

短标签：

> 建议优先关注安全与专业支持

正文：

> 您的作答显示，当前关系中高自恋互动特征与高冲突婚姻风险信号较为显著。对方可能在多个维度上表现出强烈的自我中心、羞耻暴怒、共情不足、责任外归因、操控施压、第三方动员或冲突升级倾向，这些都可能增加分居、协商、诉讼或子女安排过程中的沟通成本和现实风险。
>
> 在这一结果下，建议您优先关注自身及孩子的现实安全，避免在没有准备和支持的情况下进行激烈摊牌或高压对抗。涉及威胁、恐吓、暴力、限制行动、自伤他伤威胁、隐私公开、持续骚扰等情形时，应及时寻求现实支持、报警、申请保护措施或咨询专业人士。同时，建议尽早与专业婚姻家事律师沟通，系统梳理证据、风险与后续行动方案。

## 9. 结果页模块二：五维风险雷达图

### 9.1 模块目标

五维雷达图用于呈现用户作答中五类风险信号的相对分布，帮助用户理解风险结构，而不是只看总等级。

### 9.2 模块标题

建议标题：

> 五维风险结构

可选：

> 风险信号分布

### 9.3 维度短名

雷达图建议使用短名：

| 维度代码 | 完整名称 | 雷达图短名 |
|---|---|---|
| N1 | 自我重要感与特权感 | 特权 |
| N2 | 赞赏依赖与羞耻暴怒 | 暴怒 |
| N3 | 共情缺损与责任外归因 | 共情 |
| N4 | 操控剥削与第三方动员 | 操控 |
| N5 | 高冲突升级与安全风险 | 升级 |

### 9.4 雷达图说明文案

建议文案：

> 雷达图用于呈现五类风险信号的相对分布。某一维度分数较高，并不等于对方被诊断为某种人格障碍，而是提示该类互动模式更值得结合现实事件进一步关注。

### 9.5 维度分数展示

雷达图下可展示五维分数列表：

- 自我重要感与特权感：{score} / 5；
- 赞赏依赖与羞耻暴怒：{score} / 5；
- 共情缺损与责任外归因：{score} / 5；
- 操控剥削与第三方动员：{score} / 5；
- 高冲突升级与安全风险：{score} / 5。

### 11.6 未触发时卡片正文

## 12. 结果页模块五：下一步建议

### 12.1 模块目标

下一步建议模块用于给用户提供轻量、可执行的行动方向。

第一阶段不展开完整详细报告，仅提供简短建议。

### 12.2 模块标题

建议标题：

> 接下来可以先做什么

可选：

> 建议您优先完成的几件事

### 12.3 建议内容

建议以卡片或列表展示：

1. **记录具体事件**  
   不只记录情绪感受，也尽量记录时间、地点、对话内容、涉及人员和后续影响。

2. **保存关键证据**  
   包括聊天记录、转账记录、威胁恐吓内容、报警记录、就医记录、照片视频、证人线索等。

3. **减少无准备的正面冲突**  
   如果对方容易升级冲突，尽量避免在没有准备、没有支持的情况下激烈摊牌。

4. **优先处理安全问题**  
   如存在威胁、暴力、限制行动、自伤他伤威胁等情况，请优先联系可信亲友、报警或寻求庇护。

5. **必要时咨询专业人士**  
   涉及财产、子女、分居、离婚协商或诉讼时，可以咨询婚姻家事律师，梳理证据、风险和行动顺序。

### 12.4 低风险情况下的建议语气

低风险时建议语气应更轻：

> 当前风险信号整体较弱，但如果您已经进入分居、协商或重大权益安排阶段，仍建议理性保存关键沟通记录，避免在情绪化状态下作出重大决定。

### 12.5 高风险情况下的建议语气

高风险或高风险触发时建议语气应更明确：

> 当前结果提示您需要优先关注现实安全和外部支持。请避免在无准备状态下激烈摊牌，尽量保存关键证据，并在必要时报警、申请保护措施或咨询专业人士。

## 18. 页面视觉与交互原则

### 18.1 整体风格

建议延续离婚力量表已有的卡片化、清晰、正式、适合律所业务场景的视觉方向。

整体风格应避免：

- 娱乐人格测试感；
- 过度心理诊断感；
- 过强红色警报感；
- 过度营销落地页感。

### 18.2 色彩语义

由于本量表高分代表风险更高，颜色语义应与离婚力量表区分。

建议：

| 风险等级 | 颜色语义 |
|---|---|
| 低风险 | 稳定、低强度提示 |
| 轻度风险 | 温和提醒 |
| 中度风险 | 明确关注 |
| 高风险 | 安全优先提示 |

注意：

- 不建议全页大面积使用高饱和红色；
- 高风险提示卡可使用更醒目的边框或提示色；
- 雷达图颜色应避免让用户误以为高分是优势。

### 18.3 移动端优先

前台页面应优先保证手机端体验：

- 首页标题不宜过长挤压；
- 答题选项按钮足够大；
- 结果页模块单列排列；
- 留资输入框易填写；
- 导出按钮明显；
- 高风险提示卡不应被折叠到过深位置。

### 18.4 可读性

题目和结果页文案应保持行距充足。

涉及安全提示时，不宜用大段密集文字，应适当分段。

## 22. 阶段性结论

本文件确认了《配偶高自恋特质与高冲突婚姻风险自测量表》第一阶段公开前台的信息架构与页面文案口径。
