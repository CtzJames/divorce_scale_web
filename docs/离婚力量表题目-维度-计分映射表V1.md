# 离婚力量表题目-维度-计分映射表 V1

## 1. 文档用途

本表用于将《离婚力量表》转化为网页端可配置题库，作为前端展示、跳题控制、反向计分、动态满分计算、结果输出的直接配置依据。

本表默认遵循以下规则：

- 所有题统一提供“与本人情况无关”选项；
- 选择“与本人情况无关”后，该题不计分；
- 所有参与计分的题目均按 1-5 分计；
- 反向题按反向计分规则换算；
- 得分率按动态满分计算，即：实际总得分 ÷（实际参与计分题目数 × 5）× 100%；
- 非跨境婚姻用户默认跳过第七维全部题目；
- 跨境婚姻用户是否进入第七维，由答题过程中的分流节点控制。

## 2. 字段定义

| 字段名                                          | 含义           |
| -------------------------------------------- | ------------ |
| question\_id                                 | 题目唯一编号       |
| dimension\_code                              | 维度编码         |
| dimension\_name                              | 维度名称         |
| question\_no                                 | 题目在全量题库中的顺序号 |
| question\_text                               | 题干           |
| option\_type                                 | 选项类型         |
| reverse\_scored                              | 是否反向计分       |
| cross\_border\_only                          | 是否仅跨境婚姻显示    |
| allow\_not\_applicable                       | 是否允许“不适用”    |
| included\_in\_total\_when\_answered          | 作答后是否纳入总分    |
| included\_in\_dimension\_avg\_when\_answered | 作答后是否纳入维度均分  |
| notes                                        | 备注           |

说明：

- 本量表所有题的 `option_type` 暂统一为 `likert_5`；
- 本量表所有题的 `allow_not_applicable` 暂统一为 `true`；
- 本量表所有题的 `included_in_total_when_answered` 暂统一为 `true`；
- 本量表所有题的 `included_in_dimension_avg_when_answered` 暂统一为 `true`。

## 3. 选项配置标准

### 3.1 标准 5 分选项

- 完全不符合（1分）
- 不太符合（2分）
- 一般（3分）
- 基本符合（4分）
- 完全符合（5分）
- 与本人情况无关（不计分）

### 3.2 反向计分规则

| 原选择   | 原分值 | 反向题实际得分 |
| ----- | --- | ------- |
| 完全不符合 | 1   | 5       |
| 不太符合  | 2   | 4       |
| 一般    | 3   | 3       |
| 基本符合  | 4   | 2       |
| 完全符合  | 5   | 1       |

## 7. 计分引擎规则草案

### 7.1 单题计分

- 普通题：按用户选择的 1-5 分直接计分；
- 反向题：按反向换算表计分；
- 选择“与本人情况无关”：返回 `null`，不计分。

### 7.2 总分计算

`total_score = 所有参与计分题目的实际得分之和`

### 7.3 动态满分计算

`effective_question_count = 所有实际参与计分的题目数`

`dynamic_full_score = effective_question_count × 5`

### 7.4 得分率计算

`score_rate = total_score ÷ dynamic_full_score × 100%`

### 7.5 结果分级

- `score_rate >= 80%` → 准备充分
- `60% <= score_rate <= 79%` → 准备一般
- `score_rate < 60%` → 准备不足

### 7.6 维度均分计算

对每个维度单独计算：

- `dimension_avg = 该维度参与计分题目的总分 ÷ 该维度参与计分题目数`

### 7.7 短板维度识别

建议规则：

- 若某维度平均分 < 3，则标记为短板维度；
- 结果页重点展示所有短板维度；
- 若无维度平均分 < 3，可展示最低的 1-2 个维度作为相对短板。

## 8. 系统分流题补充方案

为避免无子女用户与非跨境婚姻用户在整维题目中大量选择“不适用”，建议在正式计分题之前补充两条不计分系统分流题，用于控制整维显示与后续结果页展示。

### 8.1 系统分流题一：是否有未成年子女

建议字段：

- `question_id`: `SYS_CHILD_GATE`
- `question_type`: `system_gate`
- `counted`: `false`
- `trigger_target_dimension`: `D3`
- `show_condition`: 默认显示

建议题干：

- 您当前是否存在需要在离婚中一并考虑抚养、探望或共同养育安排的未成年子女？

建议选项：

- 是
- 否

分流规则：

- 选“是” → 进入 D3 子女抚养与亲子关系处理维度
- 选“否” → 整维跳过 D3

结果页规则：

- 若 D3 被系统分流整维跳过，则结果页不显示 D3 维度，也不将其列入短板分析
- 但在结果数据结构中保留 `dimension_skipped_by_gate: true`

### 8.2 系统分流题二：是否属于跨境婚姻

建议字段：

- `question_id`: `SYS_CROSS_BORDER_GATE`
- `question_type`: `system_gate`
- `counted`: `false`
- `trigger_target_dimension`: `D7`
- `show_condition`: 在 D6 后、D7 前显示

建议题干：

- 您的婚姻是否涉及跨境因素，例如中外婚姻、境外身份或居留、境外资产、子女境外身份或跨境居住安排等？

建议选项：

- 是
- 否

分流规则：

- 选“是” → 进入 D7 跨境婚姻特别事项维度
- 选“否” → 整维跳过 D7

结果页规则：

- 若 D7 被系统分流整维跳过，则结果页不显示 D7 维度，也不将其列入短板分析
- 但在结果数据结构中保留 `dimension_skipped_by_gate: true`

## 9. 更新后的题库结构建议

### 9.1 用户可见题目结构

建议前端实际呈现顺序为：

- D1 心理素质与执行能力
- D2 经济独立与财务规划能力
- SYS\_CHILD\_GATE 是否有未成年子女
- D3 子女抚养与亲子关系处理（如触发）
- D4 婚姻中的经济控制感知
- D5 法律认知与风险应对能力
- D6 婚姻亲密关系与离婚动因
- SYS\_CROSS\_BORDER\_GATE 是否属于跨境婚姻
- D7 跨境婚姻特别事项（如触发）

### 9.2 计分规则补充

- 两条系统分流题均不计分
- 两条系统分流题均不纳入总分、动态满分、维度均分计算
- 被系统整维跳过的维度，不显示在结果页短板维度区域
- 被系统整维跳过的维度，不参与“最低维度”排序比较
